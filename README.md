# VSCode Portfolio

A modern portfolio website designed to mimic the VSCode interface, built with Angular 17.

## Features
- VSCode-themed interface with file explorer navigation
- Interactive Snake game
- Responsive design for mobile and desktop
- Lazy-loaded components for optimal performance

## Setup
```bash
npm install
npm start
```

## Build
```bash
npm run build
```

## Development
```bash
npm run watch  # Build with watch mode
npm run test   # Run unit tests
```

## Deployment
The built files will be in the `dist/` folder. Deploy to any static hosting service.

## Tech Stack
- Angular 17 (Standalone Components)
- TypeScript
- SCSS
- RxJS
